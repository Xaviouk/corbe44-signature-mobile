# CORBÉ 44 — Signature mobile

Préparation du complément Outlook mobile, dérivée du modèle de signature fourni.

1. Publier les 4 fichiers sur GitHub Pages dans le dépôt `corbe44-signature-mobile`.
2. Ajouter l’URI de redirection SPA `https://xaviouk.github.io/corbe44-signature-mobile/auth.html` dans l’application Entra existante.
3. Tester d’abord avec une affectation « Juste moi » / compte de test.
4. Charger `manifest.xml` dans Applications intégrées.

Ce paquet n’a pas encore été validé dans Outlook réel.
