CORBÉ 44 — Signature mobile

URL du manifeste à fournir lors du déploiement :
https://raw.githubusercontent.com/Xaviouk/corbe44-signature-mobile/refs/heads/main/manifest.xml

Page utilisée par Outlook :
https://xaviouk.github.io/corbe44-signature-mobile/mobile.html

À vérifier dans le tenant CORBE44 avant déploiement :
- Application Entra : CORBE44-Signature-Mobile
- Client ID : 4e53fe58-6711-4d92-b141-c90f8ca3b550
- Tenant ID : 63fb9113-5dd8-452e-9c0b-279a1e9170cc
- URI SPA : https://xaviouk.github.io/corbe44-signature-mobile/auth.html
- Autorisation Microsoft Graph déléguée : User.Read

Déployer d'abord à un seul collaborateur. Confirmer dans Outlook mobile que le complément insère la signature et que les données du profil sont correctes.
